ThunderBired MCP

複数の Gmail アカウントを横断して検索・整理するための、個人用のローカルツールです。 作者が自分のメールを扱うために作ったもので、一般配布はしていません。

何をするツールか

利用者のパソコンの中で動き、Gmail API 経由で利用者自身の Gmail に接続します。 AI アシスタント（Model Context Protocol に対応したクライアント）から、 次のような操作ができます。

  • 複数アカウントを横断したメールの検索と閲覧
  • 受信トレイの整理（アーカイブ、ラベルの付け替え）
  • 返信の下書き作成

メールの送信機能はありません。作成できるのは下書きまでで、 送信するかどうかは利用者が Gmail の画面で判断します。 メールを完全に削除する機能もありません。

要求する権限と、その理由

スコープ 理由
gmail.readonly メールの検索と閲覧。読み取り専用で登録したアカウントに使用します。
gmail.modify アーカイブとラベルの付け替え。いずれも元に戻せる操作です。 メールの完全削除ができる https://mail.google.com/ は意図的に要求していません。
gmail.compose 返信の下書きの作成。送信用の gmail.send は要求していないため、送信は技術的にできません。

データの取り扱い

認証情報とアクセストークンは利用者のパソコンの中だけに保存され、 作者を含む第三者に送信されることはありません。 ただし、利用者が AI アシスタントにメールの要約などを依頼した場合、 その処理のためにメールの内容が AI アシスタントの提供元へ送信されます。

詳しくはプライバシーポリシーをご覧ください。
